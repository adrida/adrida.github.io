# Adam Rida - Personal Website

This repository contains the source code for [adrida.github.io](https://adrida.github.io), the personal portfolio and website of Adam Rida, AI Researcher and Founder of [DeepRecall](https://deeprecall.io).

## Overview

The website serves as a central hub for my research, projects, and publications in Artificial Intelligence, Machine Learning, and Explainable AI (XAI). It highlights my work on:
- **LLM Cost Optimization & Routing**: Creator of [TRACER](https://github.com/adrida/tracer).
- **Explainable AI (XAI)**: Creator of [DeltaXplainer](https://github.com/adrida/deltaxplainer) for interpreting model differences over time.
- **Regulatory AI & Compliance**: Founder of DeepRecall, an AI-powered regulatory intelligence platform.

## Content Sections

- **About**: Background, professional experience, and current research focus areas.
- **Publications & Blogs**: Links to academic papers (e.g., DynXAI workshop at ECML-PKDD 2023) and technical blog posts on Medium.
- **Open Source Projects**: Showcase of active projects including TRACER, Temporal Augmented Retrieval (TAR), and Sales AI Whisperer.

## Development

This is a static website built with:
- **HTML5 / CSS3** using Bootstrap framework
- **JavaScript** (jQuery, Owl Carousel, Magnific Popup)
- **Icons** via Themify and Icomoon
- **SEO Optimization** with JSON-LD structured data and Open Graph meta tags
